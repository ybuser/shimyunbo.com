# shimyunbo.com

Yunbo Shim’s static research website. About, Research, and CV use a light personal profile design; Timeline uses charcoal and distinct colored experience ribbons. The About hero combines a typographic introduction with three non-navigating interest notes: research, building, and visualization. A light sketchbook below introduces trying new computer technologies and sailing, running, and climbing. The Timeline remains available in the header; the old homepage experience section and timeline CTA are removed.

## Local development

Node 22.12+ (tested with Node 24). In a restricted environment, set `ASTRO_TELEMETRY_DISABLED=1` and use a writable npm cache such as `/tmp/portfolio-npm-cache`. `npm ci`, then `npm run dev`. Run `npm run check`, `npm test`, and `npm run build` before publishing. `npm run preview` serves the build locally.

## Content

Edit `src/data/entries.ts`. Entries have stable IDs, multiple categories, summary/details, and either an event date or start/end dates. Use `ongoing: true` for current work. Dates retain year, month, day, or Spring/Fall precision. Ongoing entries appear first; completed entries sort by end/event date. Unknown month/day sorts after known values in that bucket. Semester-only entries remain labeled by semester. Do not convert estimated end dates into completed work.

Research, web CV, and Timeline use the same data. Mark `selected` for the concise CV. Publications automatically receive `/research/[id]/` pages. Add only verified links; submission is not acceptance. Multiple categories never create multiple copies of the same event. Keep raw CVs, private review notes, unapproved information, and confidential documents outside this public repository, including its Git history.

The CV page stays online, but the unfinished PDF is not published. `public/files/cv.pdf` and its download link have been removed. `scripts/generate-cv.py` writes only a local draft to `/tmp/shimyunbo-cv-draft.pdf`; do not place it under `public/` or `dist/` without renewed approval. The current static build returns 404 for `/files/cv.pdf`; older Git commits and previously downloaded/cached copies are not erased by this change. Host only cleared author manuscripts.

## Timeline

Periods use indexed organization headers and strong colored ribbons on a shared axis, with matching open typographic entries. Hover or keyboard focus isolates an interval and reveals its ribbon number; focus and reduced-motion behavior remain supported. Publications use folded paper shapes, certificates use credential cards and seals, and awards use circular medallions. Work, research, education, volunteering, community and sport use distinct SVG symbols with written labels; only the sports club receives a sports symbol. Category text and dates remain visible alongside these visual cues; the entire summary is keyboard-operable.

Eight toggle filters use OR semantics. No selected filter means All. Selection is reflected in the URL, supports back/forward, and preserves expanded entries. Native details remain usable without JavaScript. Reduced-motion settings remove animations. A deep link to a hidden entry clears filters and opens that entry. Cards preserve original date precision; visual spacing is not a duration scale.

Cards use a measured, responsive two-column layout on desktop and one column on smaller screens. `src/lib/layout.ts` builds a monotone piecewise compressed time map from recorded date buckets. Every event node and duration endpoint shares that map. Long ranges use separate central lanes; dashed lines distinguish education and activities. Card ordering uses factual end/event dates separately from geometric duration endpoints, so a December endpoint normalized to January cannot move a card ahead of the next year’s semester entries. Month-only durations span the first day of the starting month to the exclusive first day after the ending month, so adjacent months share a boundary. Labels keep their original precision; year/semester buckets remain approximate. Each duration ID owns a stable muted rail color, shared by its card edge and axis rail. Missing date parts are never displayed as invented exact dates. Semester buckets sort after known month dates within their year, matching the original data ordering. Overlap alone is not an affiliation. Add `relatedIds` only when the source explicitly establishes a relationship.

Publications use venue-first disclosures with factual status labels; paper titles and citations appear inside the details. Period descriptions and GPA also stay in details, and international school entries use their institution names without the generic school-education heading. Certificates and short academic distinctions use compact title-and-date disclosures; click or keyboard activation reveals the complete existing content. Work and research periods keep compact headings, with descriptions in their expanded details.

The bottom-right Filter menu supports OR selection, Escape, outside clicks, and focus return. ResizeObserver measures expanded cards, viewport changes, and late content; cancellable FLIP transitions rebase from current visible positions. Native details are the no-JavaScript fallback.

Browser validation: with the static preview on port 4321, run `python3 scripts/check-ui.py` (Python Playwright and Chromium required). Screenshots are written under `/tmp`.

## Deployment preparation

Build outputs `dist/`. This can be hosted as static assets on Cloudflare Workers or GitHub Pages. No server, database, credentials, or analytics are included. GitHub Actions checks types, runs tests, builds, and uploads a static-site artifact on each push to master. Review the content, PDF, domain settings, and hosting limits before publishing. The owner has authorized pushes to this repository and deployment of this website. Existing services and mail DNS must be preserved. Obtain specific approval for paid services, new persistent credentials, or replacement of another existing service. Never replace existing mail DNS records.

## Cloudflare deployment

`wrangler.jsonc` describes a static-assets-only Worker named `shimyunbo-com`. No custom-domain route is hard-coded, so deployment cannot silently overwrite DNS. With an authorized Cloudflare connection, run `npm run deploy`. Alternatively connect this repository in Cloudflare Workers Builds using build command `npm run build` and deploy command `npx wrangler deploy`. Select the master branch.

Before attaching `shimyunbo.com` as a Worker Custom Domain, inspect current DNS and web hosting. Preserve MX/TXT records and unrelated services. If an existing website would be replaced, ask the owner. Verify the workers.dev deployment first, then the custom domain and TLS. Cloudflare authentication and domain attachment were not completed in the development environment. Do not place credentials in this repository.

The duration lens is a circular magnifying glass showing an optical crop of the actual timeline SVG at the touched point. The same scale and translation apply to every line, endpoint, node and year label. Select a magnified line itself; invisible, non-overlapping hit strips retain the true temporal endpoints. Dense lanes are enlarged to at least 44px separation; drag within the circle to inspect cropped neighboring lines. The Source marker identifies the original sample when viewport edges shift the lens. Keyboard users can activate the small magnifier button beside the Timeline title, use Left/Right to focus lines and Up/Down to pan time, then Enter to select or Escape to dismiss. Selection opens/focuses the entry; outside clicks only dismiss. Scrolling, filtering and resizing close the glass. Run `python3 scripts/check-glass.py` alongside `scripts/check-ui.py` against the preview.
